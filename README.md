# AI Monitoring Proxy

Локальный прокси к ИИ-API: подставляет API-ключ, пишет запросы и ответы в DuckDB
и показывает веб-интерфейс с логом, балансом, моделями и галереей картинок.

Подробная документация — в [DOCS.md](DOCS.md).

## Быстрый старт

```bash
make service-install   # поставить сервис: стартует сам и переживает перезагрузку
```

Откройте <http://localhost:8787/> и укажите API-ключ на странице «Настройки».

## Команды make

`make` без аргументов показывает список.

| Команда                  | Что делает                                                        |
| ------------------------ | ----------------------------------------------------------------- |
| `make install`           | Создать `.venv` и поставить зависимости (`reinstall` — с нуля)    |
| `make run`               | Запуск в переднем плане; адрес и порт — из настроек               |
| `make run-lan`           | То же, но с доступом из локальной сети (`0.0.0.0`)                |
| `make dev`               | Режим разработки: перезапуск при правке кода                      |
| `make test`              | Все тесты (`test-core` — логика, `test-web` — HTTP)                |
| `make service-install`   | Установить сервис или обновить описание старого формата           |
| `make status`            | Состояние сервиса: адрес, порт, отвечает ли                        |
| `make start` / `stop` / `restart` | Управление сервисом                                      |
| `make logs`              | Хвост журнала сервиса                                             |
| `make service-uninstall` | Снять сервис; `data/` не трогается                                 |
| `make config`            | Показать настройки, ключи замаскированы                            |
| `make backup`            | Копия базы, настроек, картинок и логотипа в `data/backup-<время>/` |

Порт для ручного запуска можно задать разово: `make run PORT=9000`.

`make backup` на время копирования останавливает запущенный сервис и сразу запускает
снова — копия открытой базы DuckDB может оказаться несогласованной. Старые копии
удаляйте вручную.
